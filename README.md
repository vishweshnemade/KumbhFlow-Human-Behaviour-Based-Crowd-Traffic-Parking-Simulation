
# KumbhFlow: Human Behaviour-Based Crowd, Traffic & Parking Simulation

KumbhFlow is a Python-based simulation project designed to simulate
crowd movement, traffic, parking availability, walking routes and
emergency situations during large-scale events such as Kumbh Mela.

## Problem Statement

Large-scale events can create problems such as:

- High crowd density
- Traffic congestion
- Parking shortages
- Improper movement of people
- Blocked routes
- Emergency evacuation difficulties

KumbhFlow provides a simulated environment to study these situations.

## Main Features

- Crowd density simulation
- Traffic congestion simulation
- Parking availability management
- Entry and exit gate management
- Walking route selection
- Emergency route simulation
- Human behaviour-based simulation
- Alternative route suggestions
- Visual output using Streamlit

## Human Behaviour

The simulation can consider different behaviour patterns:

1. Normal Behaviour
2. Rushed Behaviour
3. Confused Behaviour
4. Group Movement
5. Emergency/Panic Behaviour

Different behaviours can produce different crowd and traffic conditions.

## Site Layout

The simulated Kumbh Mela area contains:

- Entry Gates
- Exit Gates
- Multiple Grounds
- Parking Areas
- Roads
- Walking Routes
- Emergency Routes
- Stalls and facilities

## Technology Used

- Python

- Basic Python functions
